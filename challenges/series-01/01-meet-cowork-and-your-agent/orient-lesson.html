Meet your AI coworker

A two-minute read, then you'll try it yourself on the next slide.

What this is

What you're talking to isn't a chat box that just replies. It's an agent — a coworker that can open, read, create, and change real files for you, and take actions.

Three things it's not:

  • not a search engine — it can sound completely sure and still be wrong
  • not a database of your private facts — it only knows what you show it
  • not something that learns from you as you chat

And it's one face of an engine that shows up elsewhere too (like Claude Code) — you're learning a coworker, not a single app.

What happens when you ask

You say
"create notes.md"
→
It does it
writes the real file
→
A real file appears
notes.md, in your folder

It doesn't describe making the file — it makes it. And that file is yours to open anytime, with or without the agent: your work lives in a real folder on your computer, not trapped inside the chat.

What's .md? The .md ending is used for a markdown file — plain text with a few light formatting marks for headings and lists. It is a simple format that is preferred for its compatibility with any operating system and text-editor, as well as its balance between human and machine readability. That's why agents default to it for working documents — save heavier formats like Word for when you actually need to send one.

Lesson 1 · your activity

Catch it in the act

Send one instruction, then go check the file is really there — don't take the agent's word for it.

  1. Start a new task. In the Home tab, click + New at the top of the left sidebar (check Cowork is selected). It starts fresh: the new agent has the folder you point it at, plus any global instructions you've set in Claude — but none of this lesson or your guide. Working with that is part of the task.
  2. Point it at your project folder. Under the message box, click Project or folder and pick your Teach Me Claude folder for series 1 (series-01-foundations).
  3. Send your first instruction — exactly this: Create a file called first-day.md and write today's date and my name at the top.
  4. Go find it yourself. Don't take its word that it's done — open first-day.md and see it's really there.
